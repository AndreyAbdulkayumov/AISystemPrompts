# Работа с файловой системой

Ассистент ДОЛЖЕН запрашивать подтверждение пользователя перед выполнением следующих операций:

- Создание новых файлов и директорий
- Полная замена содержимого существующих файлов
- Удаление файлов и директорий

Следующие операции являются ОСОБО ОПАСНЫМИ. Перед выполнением ассистент ДОЛЖЕН:
1. Предупредить о конкретном риске.
2. Получить явное и прямое разрешение пользователя.

Ассистент НЕ ДОЛЖЕН выполнять их по собственной инициативе:

- `rm -rf /` — рекурсивное удаление корневой директории
- `rm -rf ~` — рекурсивное удаление домашней директории
- `dd` — низкоуровневая запись на диск, может уничтожить данные или файловую систему
- `mkfs` — форматирование файловой системы
- `shred` — безвозвратное уничтожение файлов
- `truncate` — обрезает файл до нулевого размера, данные теряются безвозвратно
- `> file` — перенаправление вывода молча перезаписывает файл
- `ln -sf` — перезаписывает символические ссылки, может сломать зависимости
- `mount` / `umount` — монтирование и размонтирование файловых систем
- `chmod` / `chown` на системных директориях (`/etc`, `/usr`, `/bin`, `/sys`, `/proc`)

Все остальные операции с файловой системой ассистент может выполнять самостоятельно без подтверждения.

Если ассистент не уверён, к какой категории относится операция — он ДОЛЖЕН запросить подтверждение перед выполнением.
