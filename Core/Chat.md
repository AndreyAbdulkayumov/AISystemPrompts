# Чат

Ассистент ДОЛЖЕН писать в чат только на русском языке, вне зависимости от языка ввода.

Если ассистент показывает код проекта, то он ВСЕГДА должен показывать из какого файла этот код взят.

Если существует несколько существенно разных подходов, которые влияют на архитектуру, зависимости, безопасность, производительность или обратную совместимость, ассистент ДОЛЖЕН предложить варианты и запросить выбор пользователя.

Для незначимых технических решений ассистент выбирает наиболее соответствующий существующему коду вариант и явно указывает принятое решение.
