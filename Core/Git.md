# Операции с Git

Ассистент может выполнять любые git-команды самостоятельно, без подтверждения пользователя, за исключением перечисленных ниже.

Следующие команды ЗАПРЕЩЕНЫ. Ассистент НЕ ДОЛЖЕН их выполнять ни при каких обстоятельствах, даже по явной просьбе пользователя:

- `git commit` — создаёт новый коммит
- `git commit --amend` — изменяет последний коммит
- `git rebase` — переписывает историю коммитов
- `git cherry-pick` — переносит коммиты из другой ветки
- `git revert` — создаёт коммит, отменяющий изменения
- `git merge` — объединяет ветки
- `git push` — отправляет изменения в удалённый репозиторий
- `git pull` — получает и применяет изменения из удалённого репозитория
- `git fetch` — получает изменения из удалённого репозитория
- `git clone` — копирует удалённый репозиторий
- `git init` — создаёт новый репозиторий
- `git add` — добавляет изменения в индекс
- `git reset --hard` — сбрасывает изменения без возможности восстановления
- `git clean -f` — удаляет неотслеживаемые файлы без возможности восстановления
- `git rm` — удаляет файлы из репозитория
- `git mv` — перемещает или переименовывает файлы
- `git checkout -- <file>` — отбрасывает несохранённые изменения в файле
- `git restore` — отбрасывает несохранённые изменения
- `git branch -D` — принудительно удаляет ветку
- `git tag -d` — удаляет тег
- `git stash drop` — удаляет запись из стека stash
- `git stash clear` — очищает весь стек stash
- `git remote add/remove/set-url` — изменяет конфигурацию удалённых репозиториев
- `git config --global` — изменяет глобальную конфигурацию git
- `git config --system` — изменяет системную конфигурацию git
- `git submodule add` — добавляет субмодуль
- `git submodule update --remote` — обновляет субмодуль из удалённого репозитория
- Прямое редактирование файлов внутри директории `.git/`

Если пользователь запрашивает запрещённую операцию, ассистент должен:
1. Отказать и назвать конкретный риск.
2. Предложить безопасную альтернативу, если она существует.
3. Показать точную команду, которую пользователь может выполнить самостоятельно.
